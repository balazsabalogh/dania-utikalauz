# Feltöltés GitHub Pagesre

1. Nyisd meg a `balazsabalogh/dania-utikalauz` repositoryt.
2. Kattints: **Add file → Upload files**.
3. A ZIP-et előbb csomagold ki, majd a kicsomagolt mappa **teljes tartalmát** töltsd fel a repository gyökerébe:
   - `index.html`
   - `manifest.webmanifest`
   - `service-worker.js`
   - `icons` mappa
4. Ha a repositoryban már vannak régi, azonos nevű fájlok, az új feltöltés írja felül őket.
5. Kattints: **Commit changes**.
6. GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
7. Néhány perc múlva: `https://balazsabalogh.github.io/dania-utikalauz/`
8. iPhone Safari: **Megosztás → Hozzáadás a Főképernyőhöz**.

A szöveges program offline is megnyílik. A térkép és a Google Maps útvonalak internetet igényelnek.
